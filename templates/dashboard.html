AWS Production Surface & Network Architecture
1. Ingress & Reverse Proxy PORT 443 / 80
Nginx web server terminating TLS 1.3 with automated Let's Encrypt certificates (Certbot). Forwards internal traffic to Gunicorn on port 5000.
2. Compute & Containerization DOCKER
AWS EC2 t3.micro running Amazon Linux 2023. Containerized Python 3.12 Flask API served with multi-worker Gunicorn WSGI.
3. Persistent Storage Pool AMAZON S3
Incident payloads stream directly to s3://argus-alerts-vamsi-2026/alerts/ authenticated via IAM Instance Role (zero credential leaks).
4. Telemetry Daemon SYSTEMD
Autonomous Python service monitor.service evaluating disk usage, CPU saturation, and sshd authentication anomalies every 60s.
